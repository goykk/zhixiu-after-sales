# DH-200 故障码速查

| 故障码 | 含义 | 常见根因 |
| --- | --- | --- |
| E101 | 电源输入异常 | 插头松动、插座无电 |
| E103 | 网络通信异常 | 配网失败、模块离线 |
| E105 | 制冷系统保护 | 压缩机、换热器堵塞、制冷剂不足 |
| E106 | 风扇转速异常 | 风扇卡阻、电机轴承、驱动板 |
| E108 | 湿度传感器异常 | 传感器失效、信号线异常 |

## E106 判定

- 有摩擦或刮擦声、扇叶有异物 → 风扇卡阻；
- 轴承噪音、转速波动 → 电机轴承磨损；
- 完全无声、拨动顺畅 → 驱动板供电异常。

# 故障记录

设备保存最近 15 条故障记录，可在 App「设备诊断」查看，
记录包含故障码、时间、湿度与风扇转速，可用于证据引用。
