# NovaDesk PX-220 故障码与排查手册

> 本手册为智修演示项目的模拟文档，非真实产品资料。

## 故障码总表

| 故障码 | 含义 | 常见根因 |
| --- | --- | --- |
| E101 | 整机不上电 | 电源模块无输出、电源线束虚接、插头松动 |
| E103 | 联网失败 | Wi-Fi 配网失败、路由器频段不匹配、Wi-Fi 通信模块故障 |
| E105 | 制冷异常 | 压缩机不启动、冷凝器积尘堵塞、冷媒泄漏 |
| E106 | 散热风扇异常 | 扇叶卡滞、电机轴承磨损、驱动板无输出 |
| E108 | 温度传感器异常 | 传感器读数漂移、传感器线束虚接、主控板采样异常 |

## E101 电源类排查

1. 确认插座供电正常、电源模块指示灯是否点亮。
2. 测量电源模块输出端电压；无输出判定电源模块故障。
3. 检查电源线束端子是否松动、发黑或虚接。
4. 电源正常但仍不上电，检查主控板供电与开机信号。

## E103 网络类排查

1. 确认路由器 2.4 GHz 频段开启，SSID 不含中文。
2. 重新配网，观察设备是否能扫描到热点。
3. 扫描正常但连接失败，检查 Wi-Fi 通信模块与天线。
4. 更换路由器后仍失败，判定通信模块故障。

## E105 制冷类排查

1. 确认压缩机是否启动，是否有嗡嗡声或过热保护。
2. 清理冷凝器滤网与翅片，排除积尘堵塞。
3. 检查管路接头是否有结霜、油渍，判断冷媒泄漏。
4. 压缩机不启动且供电正常，按压缩机总成故障转模块返修。

## E106 风扇类排查

1. 断电后拨动扇叶，检查是否卡滞或有异物。
2. 倾听声音：摩擦声指向异物，嗡嗡声指向电机轴承。
3. 测量驱动板输出；无输出检查驱动板与排线。
4. 清理或更换后复测转速与电流。

## E108 传感器类排查

1. 重新插接温度传感器，检查线束是否被压伤。
2. 对比面板温度与独立温度计，偏差超过 3 ℃ 判定读数异常。
3. 更换传感器仍异常，检查主控板采样通道。
