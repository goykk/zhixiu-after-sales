# NovaDesk PX-450 故障码与排查手册

> 本手册为智修演示项目的模拟文档，非真实产品资料。

## 故障码总表

| 故障码 | 含义 | 常见根因 |
| --- | --- | --- |
| E101 | 整机不上电 | 电源模块无输出、电源线束虚接、插头松动 |
| E103 | 联网失败 | Wi-Fi 配网失败、路由器频段不匹配、Wi-Fi 通信模块故障 |
| E105 | 制冷异常 | 压缩机不启动、冷凝器积尘堵塞、冷媒泄漏 |
| E106 | 双风扇异常 | 扇叶卡滞、电机轴承磨损、驱动板无输出 |
| E108 | 温度传感器异常 | 传感器读数漂移、传感器线束虚接、主控板采样异常 |

## E101 电源类排查

1. 确认插座有电、电源模块指示灯状态。
2. 测量电源模块输出；无输出判定电源模块故障。
3. 检查电源线束端子是否松动、发黑、虚接。
4. 电源正常仍不上电，检查主控板开机信号与保险元件。

## E103 网络类排查

1. 确认路由器开启 2.4 GHz 频段，SSID 使用英文或数字。
2. 重新配网，观察能否扫描到热点。
3. 扫描失败检查 Wi-Fi 通信模块供电与天线连接。
4. 模块供电正常仍失败，判定通信模块故障。

## E105 制冷类排查

1. 检查压缩机是否启动、是否进入过热保护。
2. 清理冷凝器滤网与翅片，排除积尘堵塞。
3. 检查管路接头结霜、油渍，判断冷媒泄漏。
4. 压缩机供电正常但不启动，按压缩机总成故障转模块返修。

## E106 风扇类排查

1. 断电后分别拨动两只风扇，定位卡滞的一侧。
2. 清理异物，检查扇叶是否变形。
3. 测量驱动板输出；单侧无输出检查驱动板对应通道。
4. 电机嗡嗡响、转速下降，判定电机轴承磨损。

## E108 传感器类排查

1. 重新插接传感器，检查线束是否被压伤。
2. 对比面板温度与独立温度计，偏差超过 3 ℃ 判定异常。
3. 更换传感器仍漂移，检查主控板采样通道。
