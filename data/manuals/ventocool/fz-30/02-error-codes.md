# FZ-30 故障码与排查手册

> 本手册为智修演示项目的模拟文档，非真实产品资料。

## 故障码总表

| 故障码 | 含义 | 常见根因 |
| --- | --- | --- |
| E101 | 整机不上电 | 电源模块无输出、电源线束虚接、插头松动 |
| E103 | 联网失败 | Wi-Fi 配网失败、路由器频段不匹配、通信模块故障 |
| E105 | 制冷系统异常 | 压缩机不启动、冷凝器积尘堵塞、冷媒泄漏 |
| E106 | 风扇异常 | 扇叶卡滞、电机轴承磨损、驱动板无输出 |
| E108 | 传感器异常 | 传感器读数漂移、传感器线束虚接、主控板采样异常 |

## E101 电源类排查

1. 确认断路器合闸、插头插紧，电源线束无破损。
2. 测量电源模块输出；无输出判定电源模块故障。
3. 检查接线端子是否松动、发黑、接触不良。
4. 电源正常仍不上电，检查主控板与急停回路。

## E103 网络类排查

1. 确认路由器 2.4 GHz 频段开启，信号强度足够。
2. 重新配网，检查通信模块供电与天线。
3. 模块无法扫描热点，判定通信模块故障。
4. 网关组网场景需确认网关在线。

## E105 制冷类排查

1. 检查压缩机是否启动、是否过热保护。
2. 清理冷凝器翅片与滤网，排除积尘堵塞。
3. 检查管路接头结霜、油渍，判断冷媒泄漏。
4. 测量系统高低压；压力偏低且压缩机运行，优先检漏。
5. 冷媒泄漏必须保压检漏后再补充，禁止直接加注交付。

## E106 风扇类排查

1. 断电后拨动轴流风扇，检查卡滞与异物。
2. 倾听摩擦声、嗡嗡声，判断异物或轴承磨损。
3. 测量驱动板输出；无输出检查驱动板与电容。
4. 清理后仍不转，按电机或驱动板故障处理。

## E108 传感器类排查

1. 重新插接传感器线束，检查端子是否氧化。
2. 对比面板温度与独立温度计，偏差超过 3 ℃ 判定异常。
3. 更换传感器仍漂移，检查主控板采样通道。
