# WH-3000 故障码速查

| 故障码 | 含义 | 常见根因 |
| --- | --- | --- |
| E101 | 电源输入异常 | 供电中断、插头接触不良 |
| E103 | 通信异常 | 配网失败、模块离线 |
| E105 | 制热系统保护 | 压缩机、换热器堵塞、制冷剂不足 |
| E106 | 风扇转速异常 | 风扇卡阻、电机轴承、驱动板 |
| E108 | 传感器异常 | 水温传感器失效、信号线异常 |

## E106 判定

- 有摩擦声且扇叶有异物 → 风扇卡阻；
- 轴承噪音、转速波动 → 电机轴承磨损；
- 完全无声、拨动顺畅 → 驱动板供电异常。

# 故障记录

控制器保存最近 30 条故障记录，包含故障码、时间、进出水温与风扇转速，
可用于诊断时引用为手册事实证据。
