# AC-Pro 900 故障码速查

| 故障码 | 含义 | 常见根因 |
| --- | --- | --- |
| E101 | 电源输入异常 | 断路器跳闸、电压偏低 |
| E103 | 网络通信异常 | 配网失败、网络模块离线 |
| E105 | 制冷系统保护 | 压缩机、冷凝器、制冷剂 |
| E106 | 风扇转速异常 | 风扇卡阻、电机轴承、驱动板 |
| E108 | 传感器异常 | 传感器失效、信号线异常 |

## E106 排查摘要

1. 听风扇区域是否存在摩擦声或完全无声。
2. 拍照记录扇叶与出风口是否存在异物。
3. 断电后拨动叶片，判断是否卡滞。

# 故障码与保修

- 保修期内 E106 由卡阻或积尘引起的清洁服务免费。
- 电机与驱动板更换需提供故障记录截图。
- 人为拆装造成的损坏不在保修范围内。
