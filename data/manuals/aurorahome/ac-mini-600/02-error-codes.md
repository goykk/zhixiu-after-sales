# AC-Mini 600 故障码与排查手册

> 本手册为智修演示项目的模拟文档，非真实产品资料。

## 故障码总表

| 故障码 | 含义 | 常见根因 |
| --- | --- | --- |
| E101 | 整机不上电 / 电源异常 | 电源模块无输出、电源线束虚接、插头松动 |
| E103 | 网络连接失败 | Wi-Fi 配网失败、路由器频段不匹配、通信模块故障 |
| E105 | 制冷系统异常 | 压缩机不启动、冷凝器积尘堵塞、冷媒泄漏 |
| E106 | 风扇 / 风量异常 | 扇叶卡滞异物、电机轴承磨损、驱动板无输出 |
| E108 | 温度传感器异常 | 传感器读数漂移、传感器线束虚接、主控板采样异常 |

## E101 电源类排查

1. 确认插座有电、插头插紧，电源线束无破损与虚接。
2. 测量电源模块输入端电压；输入端正常而输出端无电压，判定电源模块故障。
3. 检查接线端子是否有发黑、松动或接触不良痕迹。
4. 以上均正常仍不上电，转主控板供电支路检查。

## E103 网络类排查

1. 确认路由器开启 2.4 GHz 频段，设备与路由器距离小于 10 m。
2. 重新配网；连续三次失败后检查 Wi-Fi 通信模块供电与天线连接。
3. 模块供电正常但无法扫描到热点，判定通信模块故障。

## E105 制冷类排查

1. 听压缩机是否启动；不启动时检查启动电容、过热保护与供电。
2. 观察冷凝器翅片是否积尘堵塞，滤网是否完全堵死。
3. 检查管路接头是否有结霜、油渍，判断冷媒泄漏。
4. 冷媒泄漏需先保压检漏，禁止直接补充冷媒后交付。

## E106 风扇类排查

1. 断电后手动拨动扇叶，感受是否有卡滞或明显阻力。
2. 倾听运行声音：摩擦或刮擦声指向扇叶异物；嗡嗡声指向电机轴承磨损。
3. 测量驱动板输出电压；驱动板供电正常但电机不转，判定电机故障。
4. 清理异物后仍不转，按电机或驱动板故障处理。

## E108 传感器类排查

1. 重新插接温度传感器插头，检查线束是否被压伤。
2. 对比面板显示温度与室温，偏差超过 3 ℃ 判定读数异常。
3. 更换同型号传感器后仍漂移，检查主控板采样通道。
